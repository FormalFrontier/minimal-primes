thirteen modules in all. The principal-quotient theorem
[`Ideal.associatedPrimes_quotient_span_singleton_eq_minimalPrimes`](../MinimalPrimes/AssociatedPrincipal.lean)

The [scalar-restriction leaf](../MinimalPrimes/AssociatedRestrictScalars.lean)

source and semiring target. Over commutative semirings, associated primes contract
along any compatible algebra map and reflect along a surjective one. The
[principal-quotient leaf](../MinimalPrimes/AssociatedPrincipal.lean) also characterizes
quotient-spectrum points under the same ring hypotheses, for every `f`: being associated
over the quotient ring and being the exact annihilator of an element are each
equivalent to minimality of the forward ideal comap above `(f)`. The exact-annihilator
criterion is separate from the radical-of-annihilator associated-prime criterion.

## Module `MinimalPrimes.Principal`

> # Minimal primes over a principal ideal in a UFD
>
> This file classifies the minimal primes over a nonzero principal ideal in a
> commutative unique factorization domain. The classification uses membership in
> the multiset of normalized factors, and therefore deliberately forgets factor
> multiplicity. The caller supplies a `NormalizationMonoid` instance, so the factors
> in the results use the caller's chosen normalized representatives. All results
> assume the element is nonzero; units have no factors or minimal primes above
> their principal ideal.

[Module source](../MinimalPrimes/Principal.lean)

### Ideal.minimalPrimes_span_singleton_eq_normalizedFactors

```lean
theorem Ideal.minimalPrimes_span_singleton_eq_normalizedFactors {R : Type u} [CommRing R] [UniqueFactorizationMonoid R] [NormalizationMonoid R] {f : R} (hf : f ≠ 0) : (span {f}).minimalPrimes = {P : Ideal R | ∃ p ∈ UniqueFactorizationMonoid.normalizedFactors f, P = span {p}}
```

The minimal primes over a nonzero principal ideal in a commutative UFD are
the principal ideals generated by the normalized irreducible factors.

Membership in `normalizedFactors f` is a proposition about a multiset, so this
set equality intentionally forgets the multiplicity of repeated factors.
The proof factors `f` up to association, uses primality to select a factor of
the product, and uses minimality in both directions. The nonzero assumption
excludes zero, whose empty factor multiset does not classify `(0)`.

[Source](../MinimalPrimes/Principal.lean#L35) (line 35).

### Ideal.normalizedFactorsEquivMinimalPrimes

```lean
noncomputable def Ideal.normalizedFactorsEquivMinimalPrimes {R : Type u} [CommRing R] [UniqueFactorizationMonoid R] [NormalizationMonoid R] {f : R} (hf : f ≠ 0) : { p : R // p ∈ UniqueFactorizationMonoid.normalizedFactors f } ≃ ↑(span {f}).minimalPrimes
```

The normalized factor *values* of a nonzero element are equivalent to the
minimal primes over its principal ideal. The forward map sends a factor to its
principal ideal; `Equiv.ofBijective` selects the inverse noncomputably. Repeated
occurrences of a factor are not separate elements of the subtype.

[Source](../MinimalPrimes/Principal.lean#L87) (line 87).

### Ideal.normalizedFactorsEquivMinimalPrimes_apply

```lean
theorem Ideal.normalizedFactorsEquivMinimalPrimes_apply {R : Type u} [CommRing R] [UniqueFactorizationMonoid R] [NormalizationMonoid R] {f : R} (hf : f ≠ 0) (p : { p : R // p ∈ UniqueFactorizationMonoid.normalizedFactors f }) : ↑((normalizedFactorsEquivMinimalPrimes hf) p) = span {↑p}
```

The factor-to-minimal-prime equivalence sends a normalized factor to its
principal ideal. This forward-map equality holds by `rfl` and is a simp lemma.

[Source](../MinimalPrimes/Principal.lean#L121) (line 121).

## Module `MinimalPrimes.IrreducibleComponents`

> # Irreducible components of a principal zero locus in a UFD
>
> This file composes the normalized-factor/minimal-prime equivalence with mathlib's
> minimal-prime/irreducible-component correspondence for the zero-locus subspace
> of `PrimeSpectrum R`. The codomain is order-dual; the result is an `Equiv`, not a
> homeomorphism or a classification of arbitrary ideals.

[Module source](../MinimalPrimes/IrreducibleComponents.lean)

### Ideal.normalizedFactorsEquivIrreducibleComponents

```lean
noncomputable def Ideal.normalizedFactorsEquivIrreducibleComponents {R : Type u} [CommRing R] [UniqueFactorizationMonoid R] [NormalizationMonoid R] {f : R} (hf : f ≠ 0) : { p : R // p ∈ UniqueFactorizationMonoid.normalizedFactors f } ≃ (↑(irreducibleComponents ↑(PrimeSpectrum.zeroLocus ↑(span {f}))))ᵒᵈ
```

The normalized factor values of a nonzero element are equivalent to the
order-dual irreducible components of the zero-locus subspace of its principal
ideal in `PrimeSpectrum R`. Composes `normalizedFactorsEquivMinimalPrimes` with
mathlib's `minimalPrimes.equivIrreducibleComponents` and forgets its order
structure with `toEquiv`; the inverse is noncomputable.

[Source](../MinimalPrimes/IrreducibleComponents.lean#L32) (line 32).
